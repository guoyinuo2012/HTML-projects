Application Architecture Overview 1. Single-File Encapsulation: Complete HTML layout, CSS rules, themes, animations, icons, and JavaScript logic are bundled inside index.html. 2. Audio Playback Engine: Leverages the HTML5 Audio API for playback control, progress scrub/drag, volume buffering, and seamless track looping/transition. 3. Web Audio Visualizer: Uses an AudioContext with an AnalyserNode performing real-time Fast Fourier Transform (FFT) analysis. An animated multi-band equalizer is rendered onto an HTML5 via requestAnimationFrame with an automated synthesizer fallback if CORS is restricted. 4. Data Persistence: Playlists, track additions/removals, favorites, volume levels, shuffle, repeat mode, and theme configurations are saved in localStorage. 5. Responsive & Accessible: Features full responsive breakpoints for mobile, tablet, and desktop, complete with keyboard shortcuts (Space, ←, →, ↑, ↓, M, L, S, R).
